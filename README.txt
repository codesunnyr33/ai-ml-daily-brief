AI/ML Daily Brief — local dashboard

Open dashboard.html in your browser (keep this whole folder together).

Tabs
- Today: latest brief + export buttons
- Archive: all prior days, group by day/week/month, expand/collapse, quick search

Refresh
- Click Refresh to reload briefs-data.json from this folder (no new zip needed).
- Each morning the agent syncs updated files into this folder on your laptop.

One-time setup
1. Unzip once to a permanent place, e.g. Desktop\AI-ML-Daily-Briefs
2. Bookmark dashboard.html
3. Approve the agent's daily sync to that folder (reply with the path)
